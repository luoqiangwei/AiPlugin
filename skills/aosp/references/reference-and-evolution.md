# 文档、实现与版本演进

## 如何理解这份知识库

Google AOSP 文档是持续更新的工程文档，包含 Getting Started、Core Topics、Security、Compatibility、Devices、Automotive 与发布变更；API reference、源代码、CDD 和安全公告承担不同证据职责。页面数量不是领域理解程度，导航覆盖也不能证明没有孤立页面。

本知识库保留以下资料，并分别记录语义深度和采集状态：

1. 领域文件是原创归纳，解释机制、边界和可以据此作出的判断。
2. `sources/catalog.jsonl` 保存公开文档的标题、URL、状态、正文指纹和技术标识符，用于定位原文；不分发整站正文副本。
3. `sources/coverage.json` 记录采集范围、发现方式、待处理与不可访问页面。`body_extracted` 仅表示正文被结构化提取，不能解释为每条内容已被专家审定。
4. [主题深度核对表](sources/topic-coverage.md) 对照主要栏目列出机制提炼、概览与仅检索入口；已知薄弱处不计作已完成知识覆盖。
5. [实际侧边栏](sources/sidebar.json) 递归跟随栏目标签，保留折叠标题与后代；[归属规则](sources/sidebar-routes.json) 给出本地候选文件，直接引用另行记录。路由和引用都不把整个叶子全文自动标为语义完成，HTML 获取时间也与本地核对时间分别保留。

## 规范与实现不能混为一谈

- **CDD** 规定某版本 Android 兼容设备的要求；适用性可能依赖设备类别、launch level、功能声明和条款条件。不能把所有 `MUST` 从不同设备类别机械合并。
- **CTS/VTS 等测试** 是可执行验证的一部分。测试通过不能修改 CDD 要求，测试缺失也不意味行为没有契约。
- **平台机制文档** 说明设计意图和集成方式，可能描述最新实现。修改旧分支时要查当时可用的接口、构建变量和迁移状态。
- **源码及构建配置** 确定当前产品实际启用的路径。相同 Android 主版本的 BSP、回移补丁与构建变体也可能不同。
- **API reference** 用于核对符号、签名和声明，不独立证明运行权限、线程语义、硬件能力或特定版本行为。
- **安全公告** 描述公开问题和修复范围，不能仅用公告月份或系统版本字符串判断厂商分支是否已回移修复。

遇到矛盾时，明确哪一方是规范、哪一方是观察到的实现，核对版本与适用条件，再分析是否存在实际不符合；不要简单宣布“源码优先于规范”。

## 版本事实如何落地

对影响结论的事实记录以下条件，缺少的项目标为未知：

| 事实 | 需要的依据 |
|---|---|
| API/模块是否存在 | 目标仓库 revision、接口/构建声明及调用点 |
| 行为何时改变 | 对应版本文档、变更历史、测试或回移提交 |
| 对哪个设备适用 | 产品配置、feature 声明、设备形态、launch level |
| 跨版本能否通信 | 版本化接口、稳定性声明、冻结内容、VINTF 或模块契约 |
| 安全修复是否交付 | 受影响代码路径、修复提交及回移差异、实际镜像 |
| 某次验证是否有效 | 源码与补丁、产物、设备镜像、执行目标与原始结果 |

同一个 feature flag 可能影响编译可见性、运行选择或发布开关，不能根据名称猜测。主干文档中的新模块拆分也不能自动适用于尚未迁移的发行分支。

## 按问题查原文

- 符号、接口和构建变量：先在目标源码查定义、调用者、测试及产品配置，再用官方文档理解契约。
- 性能、功耗、内存：先明确目标指标与负载，查相关机制和测量方法；文档中的示例数字不是当前产品预算。
- 权限与安全：追踪实际调用身份、用户作用域及访问控制，结合对应机制的适用条件，避免只按 API 名称判断。
- 兼容与更新：同时核对旧/新版本及回滚组合，关注数据和状态的兼容，而不仅是函数签名。
- 车载、TV、虚拟化等设备：使用对应设备类别的规范和架构，不能从手机经验直接外推。

本地检索工具对标题、URL 路径和技术标识符排名；命中是导航结果，不是答案证明。未命中也不能证明 AOSP 不支持某能力。

## 资料维护的可验证边界

采集工具只递归发现 `https://source.android.com/docs` 下的英文规范地址，合并翻译查询参数，记录请求与解析状态。生成式 API reference 位于 `/reference`，以官方入口查阅，不将每个类、方法或设备二进制分发页复制为规则。外部代码仓库、开发者文档和 PDF 规范按实际问题读取。

因此，全站目录、正文采集、领域提炼与针对具体结论的核实需要分别报告。站点地图失效、HTTP 错误、导航孤立页和后续新增内容不会被静默计作已完成覆盖。

## 官方依据

- [AOSP 文档总入口](https://source.android.com/docs)：资料体系与主要领域。
- [Core Topics](https://source.android.com/docs/core)：平台子系统与功能分组。
- [发布说明](https://source.android.com/docs/whatsnew/release-notes)：版本变化入口，实际适用性仍需对应分支。
- [Compatibility Definition Document](https://source.android.com/docs/compatibility/cdd)：版本化兼容要求。
- [Android 安全公告](https://source.android.com/docs/security/bulletin)：公告、受影响范围与修复链接。
- [官方 API reference](https://source.android.com/reference)：HAL、HIDL、Tradefed 等符号资料入口。
- [Android Code Search](https://cs.android.com/)：公开源码定位；选择与目标环境一致的分支或 revision。
