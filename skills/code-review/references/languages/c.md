# C：整数运算、对象生存期与初始化

先确认 C 标准版本、整数宽度和实际编译选项。本文件补充语言与标准库语义；内核锁、中断上下文和设备内存访问转相应运行场景，通用所有权与并发推导沿用公共规范。示例省略头文件，`reject()` 表示终止当前操作。

## 有符号溢出不能靠结果回绕检测

遇到长度计算、边界递增或乘加表达式，先确定整数提升和通常算术转换后的**运算类型**。普通有符号运算溢出是未定义行为；把结果存入更宽类型或运算后检查负数，不能挽救已经发生的溢出。

```c
size_t bytes = (size_t)(count * width); // count、width 为 int：乘法仍先按 int 计算
// 已证明 a、b 均为非负 int 时，在加法前检查：
if (a > INT_MAX - b) reject();
int sum = a + b;
```

**确认条件**：给出合法可达的操作数，使实际运算类型越界且结果影响分配、循环或判断；同时检查 `INT_MIN / -1` 与 `-INT_MIN` 等边界。**反证**：所有操作数已有足够范围证明，或实际编译模式明确规定相应回绕语义；后者仍需证明回绕符合功能契约。用目标类型极值验证，不能凭调试构建“正常回绕”判安全。

## 转成大小类型之前保留负值与范围信息

遇到有符号计数进入 `size_t`、窄化赋值、索引比较或分配大小，沿表达式追踪每次隐式转换。负数转无符号会成为较大的非负值；显式 cast 只改变转换，不提供范围证明。无符号乘法即使按模回绕有定义，也可能分配过小。

```c
// count 是有符号整数；items 的元素类型已确定。
if (count < 0 || (uintmax_t)count > SIZE_MAX / sizeof *items) reject();
size_t bytes = (size_t)count * sizeof *items;
```

**确认条件**：负值、截断或乘法回绕可使检查与后续字节数/元素数不一致；核对检查与使用是否采用相同类型和单位。**反证**：范围已在转换前成立，分配与访问使用同一已验证数量；协议明确需要的掩码/模运算无需改为拒绝。验证负数、目标上界与刚超上界，不能只扩大左侧变量类型。

## 指针仍有地址不代表对象仍存在

遇到返回指针、保存局部数组地址或释放后的别名，确定被指对象的存储期。自动对象离开其生存期后不能继续引用；`const` 和指针变量自身更长的存储期都不延长被指对象生存期。

```c
const char *label(void) {
    char text[] = "ready";
    return text; // 调用方取得指针时 text 已结束生存期
}
```

**确认条件**：存在对象生存期结束后的实际求值/访问路径，不能以地址尚未被覆盖作反证。**修复与验证**：按接口契约返回独立存储、写入调用者缓冲区或使用确需的静态存储，并确认长度与共享语义。**反证**：借用仅在对象生存期内同步使用，或对象确有覆盖全部使用的存储期；不因返回指针本身报错。

## 每条读取路径都应有确定的初始化来源

遇到未初始化的自动标量、部分赋值结构体、`malloc` 或扩容后新增区域，追到第一次值读取；动态分配成功不表示内容已初始化。只在成功分支写值，却在失败分支继续读取，是 C 语义问题。

```c
int selected;
if (found) selected = 7;
return selected; // found 为假时没有确定的已存值
```

**确认条件**：某条可达路径读取未初始化的普通标量或把未写区域作为有效数据消费。**反证**：读取前在全部路径完整赋值；静态存储期对象已有语言规定的初始化；仅保留尚未读取的未初始化工作区不构成该缺陷。优先补齐缺失分支，零初始化只有在零确为合法默认状态时才满足功能契约。
